## ⚠️ 为什么它必须进仓库（2026-10-14 的教训）

线上是 **CI 全新检出 → `pnpm run build` → 推 `dist/`**。素材原本只在
`public/fd2/`（**gitignore**）⇒ CI 里没有 ⇒ **制品里没有素材** ⇒
线上**静默退回程序化绘制**。表现是"线上的人物和 Boss 变成了程序画的"，
而**任何测试都不会红**（代码路径本来就有"找不到素材就回退"的设计）。

⇒ 所以这里放的是**裁剪后的必要子集**：仓库只多 1.6MB，而制品与线上一致。
