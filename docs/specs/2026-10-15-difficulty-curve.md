### 0b. ⚠️ 难度主轴：**加"防御的难度"，不加伤害**（2026-10-16 定）

用户原话：

> 我觉得 **狂暴 就已经是加伤了**，而且我们游戏 **挨几次打 就死了 加太多伤
> 没意义**。要**增加 防御的难度**。

判据（写新机制时先过这一条）：

- **不许**用"伤害更高 / 更快 / 必中"来加难度 —— 玩家总共就那么几刀的血，
  伤害再加只是把**同一道题**变成"更早死"，不是新题
- 要加的是**防御这道题的难度**：什么时候防、用哪种防（打断 / 避 / 卸）、
  防得住吗、防的代价（炁 / 缠 / 冷却 / 姿态时长）
- 已经在候选里的四条要按这条重新过一遍（"伤害 −5"是**反例方向**：
  它压的是**输出**，不是加伤 ✓ 不冲突）

| 5 | **回炁变慢** | **×0.8**（10/秒 → **8/秒**，"只慢一点"） | ⚠️ 要加：**不能直接乘 0.8**（`changeResource` 是 `Math.round` ⇒ 每步 +0.8 照样 +1；走 `energyRegen` 又会被 `floor` 吃掉 ⇒ 0）。用**整数节奏**：每 5 个逻辑步只回 4 点 —— 见 [实施计划](../plans/2026-10-16-difficulty-curve.md) §2.1 |

### 1a. 「色欲」二阶段到底指什么（用户 2026-10-20 问）

**它一阶段现在是**（`data/lustBoss.ts`）：

```
它挨打 → 给自己挂「欲望印记」（3 秒、**不刷新**）
带着印记时你再打它 → 反伤 18（不吃增伤/减伤）+ **消耗掉印记**
  ⇒ 于是每次反伤之后都有一个明确的 3 秒安全窗 —— 这是"打它要挑时候"的博弈
```

**二阶段要改成**：把它从"**你晚一点打**"变成"**你这会儿别打**"：

**用户 2026-10-20 定的口径：反伤 + 回血 **同时**。** 也就是：

```
一阶段：挨打 → 挂印记（3 秒）→ 带着印记再挨打 → 反伤 18 + 消耗印记 → 3 秒安全窗
二阶段：**以上全部照旧**，并且**挨打就给它回一截血**（不消耗印记、也不看窗口）
        ⇒ "晚点打"不再免疫惩罚：它既反你、又在回血 —— 唯一解是**停手**
```

✅ 落地比原来**更简单**：一阶段那条 `LUST_PASSIVE` **一个字都不用改**，
二阶段的「形态 buff」自己带一条 `onHitTaken → resource(self, +hp)` 的触发器 ✓
（两条触发器同时生效 —— 这正是"同时"的意思）。

⚠️ 回多少：绝对值（与「自愈」同一个数量级起步），先按 `WHISPER_MEND_HEAL` 的
一半估，实测再调。

### 1b. 二阶段要动的引擎能力（两处小改）

| 需求 | 做法 | 量级 |
|---|---|---|
| 懒惰：**挣扎减半** | `sleepReduceMs` 现在是**每个 buff 自己的**字段（`castPipeline.strugglesOutOfSleep`），多挂一条 buff **不能**把它减半（聚合是 `max`）⇒ 加一个 `sleepStruggleMult`（0..1）到 `BuffFlags`，在那一处乘一下 | 1 个字段 + 1 行 |
| 嫉妒：**偷缠 + 无论是否命中** | 偷东西现在挂在**命中效果**里（`transfer`，闪掉就没有）⇒ 二阶段改成**能力**（`on: 'castFinish'` 的 `resource` 对）—— 能力不经过命中判定，所以"无论中不中"天然成立；再配一条内部 CD（不能每次施法都偷） | 内容 + 一条 buff 的触发器（**不用**改引擎） |

⚠️ 嫉妒的替代方案：二阶段让它**只**出抢夺那一招（其它轮转步挂 `when: notHasBuff(<二阶段标记>)`）——
更"换题"，但会让它的节奏变单调，先按上面那条做。

## 2. 曲线怎么落到"第几场"

- 一局 = 池子里每个 Boss **各一场**（`BOSS_POOL`，今天 2 个、补齐后 7 个），**顺序是洗的**
- **档位函数已经有了**：`tierForPosition(k, len) = ceil(k × 7 / len)`
  （1..7 档；短局取子集，"第一个位置最软、最后一个位置最难"永远成立）
  —— ⚠️ **今天没有任何消费者**，这是本轮要接的第一根线
- 所以机制**按档注入**，不按 Boss 写死（写死就与洗牌打架）

| 要接线的东西 | 现在在哪 | 备注 |
|---|---|---|
| 狂暴 挂不挂 / `atMs` / `dmgMult` | 每个 Boss 的 `behaviors` 里**硬写** | 按档生成行为表，或给 `makeBoss(id, tier)` 收一个难度参数 |
| 伤害门槛 −5 | 还没有（flag 本身已实现） | 给对应档的 Boss 挂一条常驻 buff / flag |
| 二阶段 | 还没有（类型已实现、内容没用过） | 每个 Boss 补一条 `onHpBelow(0.4)` + 阶段 buff / 能力 |
| 每场时限 | `app/game.ts` 的 `TIME_LIMIT_MS = 180_000`（一个常量） | **本轮不改**（"时限收紧"没被采纳） |
