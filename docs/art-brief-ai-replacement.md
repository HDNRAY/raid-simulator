# 美术替换需求 · 给"能出图、但出不了像素画"的模型

> 这份文档是**外包需求**，不是设计文档。
> 目标读者：手上有本地出图模型的人。**不需要懂代码，也不需要看懂这个仓库。**

现在的美术全部取自《炎龙骑士团2》（汉堂国际 1995），是**像素画**。
我们要做的是把它**整体替换掉** —— 角色、Boss、背景，**全部换成新出的图**。

⚠️ **前提：你的模型出不了像素画。** 那没关系 —— 这份需求**不要求像素画**，
要求的是一套**统一的高分辨率插画**。像素风由"整体一致"承担，不由单张图承担。

---

## 0. 先看要替换的东西有多少

| 类别 | 数量 | 说明 |
|---|---|---|
| 玩家角色 | **3** | 林晚风、凯丽、黛玄 |
| Boss | **7** | 七宗罪（见 §4） |
| 战斗背景 | **7** | 一个 Boss 一张 |

**单张图不需要很多，但要出的"张数"不少** —— 每个角色/ Boss 是一整套动画。
完整清单见 §2。**建议先做 1 个验证流程（见 §7）。**

## 1. 硬性规格（不满足就没法用）

| 项 | 要求 | 为什么 |
|---|---|---|
| **格式** | **PNG-32（带 Alpha 透明通道）** | 不是白底、不是 JPG。JPG 没有透明通道 |
| **背景必须是透明的** | 只有角色，**不要**地面、阴影、背景色块 | 游戏把它贴在战斗背景上 |
| **尺寸** | **512 × 512** | 游戏会缩放到屏幕上约 190px 高 |
| **角色在画面里的位置** | **水平居中；脚底对齐到画布高度的 92% 那条线** | 所有动作共用一条地平线，否则角色会"上下跳" |
| **角色高度** | 占画布高度的 **约 85%**（≈435px） | 太大会被裁、太小会显不出细节 |
| **不要自带描边/发光/特效** | 光晕、魔法圈、速度线都**不要** | 游戏做**受击闪白**（整体提亮）与位移反馈。图里再带一层光就叠成两层了 |
| **不要裁切** | 动作幅度再大也不能出画布 | 出画布就是被切掉 |

⚠️ **不需要是 2 的整数倍、不需要"像素对齐"。** 这一批走**平滑缩放**，
所以尺寸只要够大够清楚就行 —— **这是和你之前可能做过的像素图不一样的地方。**

## 2. 每个角色要出多少张

| **attack**（攻击） | **8** | 出招。**这是最常看到的一套** |
| **ult**（大招） | **10** | 只给 Boss。玩家角色**目前不需要** |

### ⚠️ 关于"动作太长"这件事

现在的素材里，有的 Boss 攻击动画有 **22 帧**、时长 **2.4 秒**。**我们不需要那么长。**

这份需求统一压到 **8 帧**，原因有两个：

1. **出图量少一半以上**（22 → 8）
2. **帧数不影响时长**：游戏会把动画**拉伸到读条时间里**播完 ——
   所以 8 帧的动作不会让技能变快，只是**动作粗一点**（像老式 3D 游戏那样）

⚠️ 所以请**不要**为了"让动作更流畅"自己加帧数。
**8 帧是刻意的**：它让出图量可控，而且**慢刀/快刀的节奏感反而更明显** —— 这正是这个游戏的核心玩法。

## 3. ⚠️ 一致性（这一步最容易失败）

**一个角色的 22 张图必须看起来是同一个人。** 这是整件事里最难的一步，
比单张画得好不好重要得多。

**唯一可靠的做法：先定稿，再派生。**

1. **先只出一张** —— idle 的第 1 帧（也就是"他是谁"那张）
2. 反复调那张，**直到你满意为止**。它就是整个角色的**唯一基准**
3. 后面 21 张**全部以它为参考**派生出来：
   - **同一个 seed + 同一段角色描述前缀**（必须逐字相同）
   - **img2img / 图生图**：把基准图当输入，只改姿势
   - 如果有 **ControlNet**：用它锁住**轮廓与五官位置**，姿势通过骨架控制
   - 有角色 LoRA 最好，没有就用上面三条

⚠️ **不要每张都从零写 prompt 重新生成** —— 那样 22 张会像 22 个人。

**自检方法**：把 22 张缩到屏幕上的实际大小（**高约 190px**）排成一条，
**快速翻动**看像不像同一个人、动作连不连贯。**在那个尺寸下看不出来的差异不算差异。**

## 4. 每个 Boss 的形象方向（七宗罪）

⚠️ 这一节是**形象要求**，不是逐字 prompt。请按你的模型自己组织提示词。

**总原则**：**每个 Boss 要在一眼之内被认出是哪个罪。**
剪影比细节重要 —— 玩家在屏幕上只看到约 190px 高的一团，
**所以轮廓、姿态、主色调必须能区分七个人**。

### 4.1 傲慢（Pride）

- **罪的形象**：不肯低头、俯视众生
- **姿态**：**重心高、下巴抬高、居高临下**。他"不屑"而不是"凶"
- **色调**：金 / 白 / 冷光
- **玩法对应**：他是**三把刀的快慢刀**（轻蔑 20 / 呵斥 40 / 碾压 60）。
  所以 attack 要有**明显不同的三个"架势"** —— 玩家靠前摇长短判断该不该闪
- **不要让**他显得粗野或愤怒（那是暴怒）

### 4.2 色欲（Lust）

- **罪的形象**：诱惑、缠缚
- **姿态**：**曲线、缠绕、接近性的动作**（伸手、拂过、贴身）
- **色调**：粉紫 + 暗红。**不要甜**，要"危险的好看"
- **玩法对应**：她有「污堕印记」（叠层）+「魅惑」（**眩晕**）。
  所以要有 **"缠住"** 与 **"侵入"** 两种动作语言

### 4.3 嫉妒（Envy）

- **罪的形象**：比较、窥视、因不足而生的恶意
- **姿态**：**瘦削、佝偻、眼神盯着你**。手上抓着自己没有的东西
- **色调**：**毒绿** + 灰
- **玩法对应**：他目前**开发中**（还没做玩法），所以**可以放开了设计**，
  留出"眼睛 / 分裂 / 模仿"这类的余地

### 4.4 暴食（Gluttony）

- **罪的形象**：吞食一切、永不满足
- **姿态**：**臃肿、前倾、巨大的口或腹腔**。动作要"沉"
- **色调**：土黄 / 褐 / 暗绿
- **玩味点**：可以做成"吞噬后变大"的形态 —— **但 idle 与 attack 必须是同一形态**
  （游戏不做形态切换）

### 4.5 暴怒（Wrath）

- **罪的形象**：纯粹的破坏冲动
- **姿态**：**低重心、前冲、大开大合**。最"重"的一个
- **色调**：**赤红 / 橙 / 黑**
- **玩法对应**：他目前开发中。这是**最适合"大动作"**的一个 ——
  但注意仍然只有 **8 帧**，靠**幅度**而不是张数表达力量

### 4.6 懒惰（Sloth）

- **罪的形象**：怠惰、停滞、不愿动
- **姿态**：**迟缓、下沉、拖着走**。动作幅度**刻意比其他人都小**
- **色调**：青灰 / 冷白 / 锈
- **设定**：这个 Boss 的底子是个**机甲队长** ✔ 可以走"机械但锈蚀、不愿启动"
- **玩法对应**：他开发中。⚠️ **别做成"行动很快"** —— 反差会毁掉这个罪

### 4.7 贪婪（Greed）

- **罪的形象**：占有、抓取、囤积
- **姿态**：**低伏、手向前抓、护着自己攒的东西**
- **色调**：**暗金 / 铜 / 黑**（和傲慢的金要**区分开**：傲慢是亮的冷金，
  贪婪是脏的暖金）
- **设定**：底子是**盗贼头目** ✔

### 4.8 三个玩家角色

这三个人**没有"罪"的约束**，但同样要**互相区分**：

| 角色 | 定位 | 建议方向 |
|---|---|---|
| **林晚风** | 主角 | ⚠️ **他是"双剑"**（原素材里就有一把在手上、一把在腰间）。请保留这个辨识点 |
| **凯丽** | 战士型 | 比林晚风更重、更硬 |
| **黛玄** | 法系 | 轻、飘、有书或法器 |

⚠️ 三个人的 **attack 必须从剪影上就能分开** —— 玩家同时看到两个人。

## 5. 背景（7 张）

| 项 | 要求 |
|---|---|
| **张数** | 每个 Boss **1 张**，共 7 张 |
| **尺寸** | **1920 × 1080**（16:9） |
| **格式** | PNG 或 JPG 都行（**不需要透明**） |
| **构图** | ⚠️ 画面**会被压满整个 960×540 的画布**，所以**必须严格 16:9**，否则会拉变形 |
| **不要有人物** | 纯场景。角色是另外贴上去的 |
| **⚠️ 要偏暗、低对比** | 游戏会在背景上压一层暗化（约 18%），顶部 128px 与底部 96px **再额外压暗**。
所以：**重要的细节不要放在最上和最下**；整体明度请**压低**，否则角色和 UI 会被背景吃掉 |
| **视角** | 与角色**同一地平线**（角色脚底在画布高度 92% 处） |

**每个背景的环境方向**（配合 Boss 的罪）：

| Boss | 环境 |
|---|---|
| 傲慢 | 高处的石造废墟 / 神殿残骸，开阔、冷 |
| 色欲 | 幽闭的洞窟或水汽弥漫的房间，紫红反光 |
| 嫉妒 | 高处的风蚀台地，苍白、空旷 |
| 暴食 | 地下洞窟、堆积的残骸，土黄、压抑 |
| 暴怒 | 火场 / 熔岩 / 焚毁的建筑，赤红 |
| 懒惰 | 废弃的机械库 / 锈蚀的工厂，青灰 |
| 贪婪 | 昏暗的宝库 / 盗贼窝，暖金反光 |

## 6. 交付方式

**目录结构**（照着放就行，`<实体>` 用 §2 表里的英文 id）：

```
art/
  player-linwanfeng/
    idle/    f00.png f01.png f02.png f03.png
    attack/  f00.png ... f07.png
  boss-pride/
    idle/    f00.png ... f03.png
    attack/  f00.png ... f07.png
    ult/     f00.png ... f09.png
  backgrounds/
    pride.png lust.png envy.png gluttony.png wrath.png sloth.png greed.png
```

英文 id 对照：

| 中文 | id |
|---|---|
| 林晚风 / 凯丽 / 黛玄 | `player-linwanfeng` / `player-kaili` / `player-daixuan` |
| 傲慢 / 色欲 / 嫉妒 / 暴食 / 暴怒 / 懒惰 / 贪婪 | `boss-pride` / `boss-lust` / `boss-envy` / `boss-gluttony` / `boss-wrath` / `boss-sloth` / `boss-greed` |

⚠️ **帧号从 `f00` 开始，必须连续**（`f00, f01, f02...`），不要跳号。
动作的顺序按**时间先后**排：`f00` 是**起手**，最后一帧是**收招**。

**idle 是循环的** —— 所以 `f03` 要能自然地接回 `f00`（首尾姿势接近）。

## 7. ⚠️ 请先只做一个人（验证流程）

**不要一次做完 197 张。** 先只做 **林晚风**（12 张），走完整条流程：

1. 你出 12 张，按 §6 放好
2. 我们接进游戏、**截实机图**给你看
3. 一起判断：**在屏幕实际大小（高约 190px）下认不认得出是他、动作读不读得懂**
4. 只调**流程和标准**，不调图
5. 定稿之后，再批量做剩下的 9 个 + 7 张背景

**理由**：这套流程里最容易翻车的是 §3 的**一致性**，
而它只有接到实机里、在真实尺寸下看才能判断。
**先花 12 张的代价把标准定下来，比做完 197 张再返工便宜得多。**

**验收就一条**：截图上，**这个角色在约 190px 高的时候还是一眼能认出来，而且 8 张攻击帧连起来读得懂发生了什么。**

## 8. 我们这边会做什么（你不用管）

- 缩放到屏幕上正确的尺寸（约 190px 高）
- 播放速率对齐到技能读条时长
- **受击闪白**（整体提亮，不是重画）+ 受击/出招位移
- 镜像（玩家朝右、Boss 朝左）—— 所以你**只需要画朝一个方向**
- 缩放到屏幕尺寸 + 播放速率对齐读条
- 透明通道与内存优化

⚠️ **游戏目前不画光晕/描边**（那层被删掉了）。所以"气场"要靠**图本身**表达，
不要指望引擎补。

**所以：你只要给出干净的、风格统一的、透明底的 512×512 序列帧就行。**
