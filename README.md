# 斗

一个**单挑 Boss**的实时战斗数值模拟器。第三人称视角、无位移、
键鼠 + 触屏操作、PixiJS 像素渲染。

**可以在浏览器里真的打完一场**：备战界面选人物与 Boss → 战斗 →
前摇预警、闪避 / 卸力 / 打断、Boss 随机出招、结算。

当前可玩：**林晚风** 对 **傲慢**（快慢刀 + 霸体）或 **色欲**（印记 + 眩晕）。
两个 Boss 共用同一引擎，区别只有行为数组。

---

## 这是什么

- **一场战斗 = 一个 Boss。** 每场有**时限**（超时判负）和**狂暴机制**
  （超时后 Boss 伤害翻倍），Boss 有带前摇的技能、阶段转换、可打断的读条。
- **没有位移，但需要"躲"。** Boss 技能在 **hit frame** 一次性判定，
  你按下的闪避 / 卸力会给自己挂一个 **短时无敌 / 阈值抵消 buff** ——
  时机对了就免伤，错了就吃满。**判定窗口就是 buff**，不是另一套系统。
- **技能派生。** 施放技能 A 后开启一个"派生窗口"，技能 B 只有在这个窗口内可用。
  同样是 buff 存在性判断。
- **玩家和 Boss 数值对等。** 两边跑**同一个引擎、同一套数据模型**，
  区别只有输入来源：玩家是键盘 / 触屏，Boss 是数据驱动的行为数组。
- **没有 WASD。** 主键区全部留给技能。

`Loadout.items` / `GameEntityInstance` 没有任何运行期消费者（见
`src/core/types/loadout.ts` 的 `Loadout`），战斗里装配不了装备。
它示范的是**数据的形状**（表达式、命名空间、动态引用），
不是"照着写就能在战斗里生效"。目前**真正会跑**的例子是 `src/data/` 里
的玩家技能与 Boss 招式。

> **2026-10-12 更新**：其中「暴击 → 触发」那条链**已经接上**
> （`onCritDealt` 补了派发点，见 `core/combat/hitResolution.ts`）。
> 但它加的 `intelligence +2` 落在**四维属性**（力 / 敏 / 智 / 精）上，
> 而那四维**目前算出来没有任何消费者** —— 这是**另一个更大的问题**，
> 不在本次范围内。

同理，`Expr.counter`（离散计数器）也**还没接线**：读它恒为 0，所以内容里
写它会被校验器报 `COUNTER_UNIMPLEMENTED` 拦下；`grantSkill` / `consume`
没有执行点，写它们会报 `ABILITY_UNIMPLEMENTED` —— 这些都是有意的
"拒绝静默误用"，不是"这些能力被否决了"（见 `AGENTS.md` §2）。

## 架构核心：一条硬边界

```
        ┌──────────────────────────────────────────────┐
        │  core/   纯确定性模拟引擎                       │
        │  (state, input, dt) -> (state', events)      │
        │  零依赖 · 无 DOM · 无 Math.random · 可在 Node 跑 │
        └──────────────────────────────────────────────┘
                 ▲                          │
      Action[]   │                          │  Snapshot + Events
                 │                          ▼
        ┌────────────────┐        ┌──────────────────────┐
        │ input/ 键鼠/触屏 │        │ render/ Pixi 消费者   │
        └────────────────┘        └──────────────────────┘
```

这条边界由五条**机器检查**的约束维持（违反则构建失败）：

1. `core/` 不许 import `pixi` / DOM / UI
2. `core/` 里不许出现 `Math.random` / `Date.now`
3. `render/` 不许反向依赖 `core/` 内部
4. `core/` 里不许出现异步
5. 状态必须可结构化克隆、可哈希

**验收标准**：`core/` 能在 Node 里跑完一整场战斗并断言结果——不启动浏览器。

## 操作

### 键鼠

一共 **9 个技能**，但**每个角色只带 5 个**（见下表"谁有"）——
技能栏与触屏按钮都**按当前角色过滤**，所以换角色时看到的格子会变。

| 键 | 字 | 谁有 | 消耗 | 效果 |
|---|---|---|---|---|
| `Q` | **斩** | 林晚风 | 15 炁 | 普攻，10 点伤害。**代价只有炁 → 打中会回缠**（10 伤 → 5 缠） |
| `F` | **劈** | 林晚风 | 50 缠 | 读条 1.2 秒，45 点伤害。⚠️ **用缠的招不回缠** |
| `E` | **凝** | 两人都有 | 50 缠 | 自身增伤 20%，30 秒 |
| `G` | **卸** | 林晚风 | 按住，**15 炁/秒**（净 −5） | 阈值抵消：**≤15 点的伤害连它带的效果一起卸掉**；>15 的只卸掉 15 点。松开即取消 |
| `S` | **避** | 林晚风 | 15 炁（1 秒 CD） | 0.5 秒完全无敌。**会打断自己的读条** |
| `D` | **拳** | 凯丽 | 15 炁 | 读条 0.25 秒，6 点伤害。**代价只有炁 → 打中会回缠**（6 伤 → 3 缠） |
| `W` | **轰** | 凯丽 | 50 缠 | 读条 0.9 秒，30 点伤害 + 易伤。⚠️ 用缠的招不回缠 |
| `R` | **截** | 凯丽 | 10 炁 | 瞬发强打断；**成功则退还冷却**，失败进入完整冷却 |
| `A` | **闪** | 凯丽 | 免费 | 0.1 秒无敌（炁见底时的兜底） |

⚠️ **回缠规则**（2026-10-12 定）：**造成伤害**会按 `伤害 × 0.5` 给**双方各回一份缠**（向下取整），
但 **施放者如果为这一击付过缠，则这一击不给它回缠**（"缠换来的伤害不再变成缠"✓）——
所以「斩」「拳」会回缠，「劈」「轰」「凝」不回。

### 设置与触屏

| 键 | 作用 |
|---|---|
| `F1` | **打开设置**（顺带暂停）。⚠️ 原来的 `Esc` / `,` 已改掉 —— `Esc` 现在用来**返回** |
| `Esc` | 在「自由模式」/「选角色」里**回首页**；战斗中**无反应** |
| `↑↓` | 首页 / 选角色：移动光标 ✓ **一局结束看日志时：滚动复盘** ✓ |
| `Enter` | 确定 / 开打 / 进下一页 |
| `T` | 设置里跳到「**触屏**」页 |

**触屏**与键盘是**两套配置**（各自的 localStorage key ✓），但**可选技能是同一个池** ✓：
设置 →「触屏」页里**点一下技能格 = 放上 / 取下**触屏按钮 ✓（键鼠在同一页用 `Enter` / `Space`）
